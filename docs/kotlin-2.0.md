# Kotlin 2.0 reference

I added this note in 2024 while exploring Kotlin 2.0. Its main compiler change was
making K2 the default. K2 concerns compiler analysis; it does not mean every
example here uses a new 2.0 language feature.

The checked-in IntelliJ configuration uses Kotlin 1.7 language/API settings and
JVM target 1.8. The cleanup keeps the examples compatible with those settings.
The check script uses whichever Kotlin command-line compiler you select, so its
reported version matters when comparing results.

[Kotlin 2.0 release notes](https://kotlinlang.org/docs/whatsnew20.html).
